# 一线牵 v2 用户端/管理端功能规格（Must-Have）

> 本文件是「用户功能完整」的验收清单。所有项目必须在 staging 以 testapp 迁移资料通过，
> 才可进入生产切换。任何降级/省略都要 ADR。
>
> **语言与界面**：全项目使用简体中文。用户端界面与操作逻辑必须与原版基本一致
> （四 tab、卡片滑动、喜欢/点赞/留言、活动/分组/一对一流程）；管理端可自行设计，
> 不受原版 UI/操作限制。

## A. 登录与账号

- [ ] A1. 手机号＋密码登录；错误信息不区分账号/密码；失败锁定与 rate limit。
- [ ] A2. 一次性 activation token：24h、一次性、设定密码后自动登录；重用/过期有明确页面。
- [ ] A3. 小天使/管理员可为用户生成临时密码；首登强制修改（P1）。
- [ ] A4. 忘记密码：管理员重置（不依赖短信）。
- [ ] A5. 退出登录：撤销 DB session、清 cookie。
- [ ] A6. 既有 testapp 用户可用 activation link 设定密码；U-0006 使用真实资料。
- [ ] A7. 账号状态门禁：待审核/审核不通过/已退出 只可看提示；disabled 不可登录。
- [ ] A8. 观察员角色可登录、只读；一般/观察员可切换（依原规则）。

## B. 注册与审核

- [ ] B1. 非飞书网页注册：手机号、姓名、性别、生日、城市/教会、照片等（依原表单；可渐进）。
- [ ] B2. 照片上传到 R2（3–9 张；JPEG/PNG；HEIC 后续）。
- [ ] B3. 身份证/手机格式校验；重复注册/重复手机阻挡。
- [ ] B4. 提交后状态「待审核」，显示联系小天使 QR/说明。
- [ ] B5. 管理员审核通过/拒绝；通过后站内通知；可生成临时密码。
- [ ] B6. 注册来源/邀请人记录；邀请关系可结算。

## C. 我的资料

- [ ] C1. 查看完整资料（分区：基本/工作/关于我/理想型/联络）。
- [ ] C2. 编辑可编辑字段；服务器端白名单/长度/选项校验。
- [ ] C3. 照片上传/删除/设封面；首页卡片按顺序展示。
- [ ] C4. 身份证格式门禁与提示；人脸/照片规则（依原规则，可先人工审核）。
- [ ] C5. 单身/已脱单切换（有有效报名时不可脱单，依原规则）。
- [ ] C6. 账号状态/注册时间/用户ID 显示。

## D. 牵线卡片

- [ ] D1. 异性卡片池：只显示符合条件、有照片、单身的用户。
- [ ] D2. 左右滑动切卡；按钮 fallback；老设备可用。
- [ ] D3. 照片横向轮播/全屏幕；第一张封面；照片审核过滤。
- [ ] D4. 卡片资料分区（基本/工作/关于我/理想型）；与原版字段一致。
- [ ] D5. 筛选：年龄、暱称/其他原版筛选；排序稳定、分页不重不漏。
- [ ] D6. 喜欢：匿名/实名、附言必填（原规则 10 字以上）、额度扣减、重复/自己/同性阻挡。
- [ ] D7. 点赞：每日上限、取消、隐私（收到数只本人可见）。
- [ ] D8. 反馈/举报；管理员处理。
- [ ] D9. 与他人资料页、留言 thread、喜欢/点赞状态联动。
- [ ] D10. 推荐位/每周推荐（若原版有；保留 pinned 隐私）。

## E. 消息

- [ ] E1. 谁喜欢我（匿名不揭露身份；实名依原规则）。
- [ ] E2. 相互喜欢列表；显示双方微信号（仅 mutual、需同意）；不依赖飞书名片。
- [ ] E3. 我喜欢的（含有效/失效/类型/附言）。
- [ ] E4. 我的留言/收到的留言；thread/reply；删除/举报。
- [ ] E5. 动态通知：喜欢/相互/审核/报名/活动/积分；未读提示。
- [ ] E6. 管理员举报列表与处理。

## F. 活动

- [ ] F1. 活动列表（报名中/已结束等）；详情（海报、时间、地点、费用、食宿、条件）。
- [ ] F2. 报名/取消；满员/重复/状态检查；缴费 QR 提示（线下）。
- [ ] F3. 我的活动；取消过滤；分组/一对一/签到入口。
- [ ] F4. 报名名单（依原 feature flag；默认与原版一致）。
- [ ] F5. 自助签到：4 位码、已到幂等、限流、错误提示。
- [ ] F6. 签到闸门：未到不可填志愿/进执行池（依原规则）。

## G. 分组

- [ ] G1. 候选异性（已报名、签到开启时只已到）。
- [ ] G2. 恰好 7 志愿、不可重复、可排序/预填/未保存守卫。
- [ ] G3. 提交/更新；并发双击不重复；状态即时可见。
- [ ] G4. 分组结果：轮次、我的组号、同组成员、看资料。
- [ ] G5. 管理台：模式、preview/run/reset/job/result/roster、执行锁与幂等。
- [ ] G6. 演算法与原版 parity（贪婪卫星滚动、志愿/红娘权重、余数分配）。

## H. 一对一

- [ ] H1. 必聊结果：轮次、对象、已聊标记（以本人给对象的非删除留言判定）。
- [ ] H2. 女生坐镇/男生上门均衡分配（min-cost flow）；K 场次。
- [ ] H3. 管理台：preview/run/reset/job/result/chat overview。
- [ ] H4. 与分组模式互斥、活动锁、轮次幂等。

## I. 麦穗/邀请/兑换

- [ ] I1. 余额=流水求和；明细；待确认邀请。
- [ ] I2. 邀请：手机号登记、7 天确认期、封禁收回、进度/链接。
- [ ] I3. 兑换：额外实名、优先报名、心愿、红娘；扣穗/开单/退还；幂等。
- [ ] I4. 取消报名退穗规则（48h）。
- [ ] I5. 管理台：总览/流水/兑换/邀请/加减穗/心愿/推荐单。

## J. 站内通知

- [ ] J1. 喜欢/实名喜欢/相互喜欢。
- [ ] J2. 审核通过/拒绝。
- [ ] J3. 报名通知（实名/匿名）。
- [ ] J4. 活动广播/变更。
- [ ] J5. 积分/兑换/邀请。
- [ ] J6. 未读/已读（可先 last_seen）；不依赖飞书。

## K. 公开页/引流

- [ ] K1. `nantou.love` 公开页：品牌、介绍、注册 CTA、QR/链接。
- [ ] K2. 非飞书注册入口。
- [ ] K3. 埋点 page_view/join_click（管理员统计）。

## L. 管理端/RBAC

- [ ] L1. 管理员登录；super_admin 可新增管理员/角色/权限。
- [ ] L2. 用户审核/查询/停用/重置密码。
- [ ] L3. 活动 CRUD/广播/名单/签到。
- [ ] L4. 分组/一对一控制台。
- [ ] L5. 麦穗/邀请/兑换/心愿/推荐单。
- [ ] L6. 举报/意见反馈。
- [ ] L7. 审计日志；最后一位 super_admin 保护。
- [ ] L8. 汇出/备份。

## M. 非功能验收

- [ ] M1. iOS 14.5+/Safari 14.1+、Chrome/WebView 84+、Firefox 74+ 完成主流程；低于范围不承诺完整用户 UI。
- [ ] M2. 首屏/图片/JS 效能预算；API p95 目标。
- [ ] M3. 安全审查：auth/session/CSRF/IDOR/rate limit/媒体/日志。
- [ ] M4. 资料迁移对账（笔数/checksum/照片/积分）。
- [ ] M5. 备份/还原演练。
- [ ] M6. 无飞书 runtime 依赖；断飞书 API 不影响 v2。
- [ ] M7. E2E 脚本覆盖登录→卡片→喜欢→留言→活动→分组→结果→麦穗。
- [ ] M8. 用户验收：与 v1 原版行为/界面基本无感（复用 v1 前端）。
- [ ] M9. 用户 SPA 的登录/API/媒体适配完成；管理端 SSR 不受影响。

## 首版明确不做

- 飞书机器人/表单/名片/Bitable runtime。
- 短信 OTP（日后可选）。
- 即时聊天/IM（改用微信号交换＋站内留言）。
- 像素级 UI 复刻。
- 微服务/K8s。
- 用户端重新设计；用户端复用 v1 前端。
- 为旧浏览器维护第二套完整用户 UI。
